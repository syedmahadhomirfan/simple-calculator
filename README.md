Objective:
Build a web-based calculator that performs basic arithmetic operations (addition, subtraction, multiplication, division) on two user-provided numbers.

⚙️ Core Features:
*Input Fields: Two text boxes for users to enter numbers.
*Operation Selection: Dropdown or radio buttons to choose the arithmetic operation.
*Calculate Button: Executes the calculation when clicked.
*Result Display: Shows the computed result or an error message (e.g., division by zero).

🖥️ Tech Stack:
*Frontend: HTML (structure), CSS (styling)
*Logic: JavaScript (calculate function with loop + control statements)

 Key Functionality:
The calculate() function:

*Uses a loop to iterate through possible operations.
*Applies control statements (if/else or switch) to determine which arithmetic operation to perform.
*Handles division by zero gracefully by returning "Division by zero is not allowed".
